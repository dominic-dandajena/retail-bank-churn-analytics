# Retail Bank Churn Analytics

Credit-card customer churn analysis using SQL Server and Power BI, framed around digital-bank competition in South African retail banking.

**Status:** in progress

## Important note about the data

- The dataset is the public Kaggle "Credit Card customers" file (10,127 customers).
- It is not South African data. It is a US-style-credit-card book, with income in USD bands.
- It is a single snapshot with no time dimension, so it cannot show how customers behave month by month.
- Findings describe associations in this dataset only. They do not prove what causes churn, and they do not describe South African customers.
- The South African context is used to frame the business questions, not to claim local results.

The raw data file is not stored in this repo. Download it from Kaggle and check the licence there.
